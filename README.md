# Uber Campus 3D Map – Mini-Prototype

A simple web prototype of our team's idea for Uber: a 3D map that helps drivers find hard-to-reach spots on university campuses like Rice University and nearby off-campus housing. The page shows a tilted 3D campus map with the route, numbered pins for key signs and food drop-off spots, and a "Next direction" button that steps through turn-by-turn directions.

**Live page:** https://yourusername.github.io/mini-prototype/

*ENTR 222 student prototype. Not an official Uber product.*
